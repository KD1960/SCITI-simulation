# SCITI 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the SCITI 1 MVP: a replicable agent-based simulation of the Ridge Line supply chain where 48 node agents adopt technologies (alone or in coalitions) via LLM decisions, with a replay web view.

**Architecture:** A pure-Python engine runs a fixed weekly loop over 48 nodes; quarterly, a pluggable `DecisionPolicy` (none / rules / mock / llm / replay) chooses technology adoptions and coalitions, with every decision logged. Runs write CSV/JSON outputs plus a manifest; a static canvas-based web page replays a run.

**Tech Stack:** Python 3.13, numpy, pandas, openpyxl, pyyaml, pydantic v2, anthropic SDK, pytest; plain HTML/CSS/JS (Canvas 2D, no JS libraries).

**Spec:** `docs/superpowers/specs/2026-09-12-sciti-1-design.md` (read it first).

The plan is split into four part files so each stays readable. Execute them in order:

| Part | File | Tasks | Ends with |
|---|---|---|---|
| A | `2026-09-12-sciti-1-partA-data.md` | 1–5 | `sciti prepare` builds `data/baseline.json` from the real workbook; demand model + network + tech catalog tested |
| B | `2026-09-12-sciti-1-partB-engine.md` | 6–10 | `sciti run configs/baseline.yaml` completes 156 weeks with invariants, outputs, manifest, golden run and calibration tests |
| C | `2026-09-12-sciti-1-partC-decisions.md` | 11–16 | rules / mock / llm / replay policies, coalitions, spend caps, batch, estimate |
| D | `2026-09-12-sciti-1-partD-view.md` | 17–19 | `sciti view RUN_DIR` replays a run on a world map with dashboard; final verification |

## Global Constraints

- Python `>=3.13`. Project root: `~/Claude/Projects/SCITI simulation/` (path has a space — always quote it in shell).
- Virtual env at `.venv/`; install with `.venv/bin/pip install -e ".[dev]"`; run tests with `.venv/bin/pytest`.
- Stage files **by name**. Never `git add -A` or `git add .`.
- Commit messages end with `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`.
- Weekly time step; horizon 156 weeks; decisions at the start of each quarter: weeks 1, 14, 27, … (12 rounds).
- 48 agents: `Supplier_1`…`Supplier_30`, `CM_1`…`CM_4`, `MFG_US`, `MFG_China`, `DC_Houston`, `DC_Dubai`, `DC_Shanghai`, `DC_Sofia`, `Retail_1`…`Retail_8`.
- BOM: 160 sub-component units per product: SR_MCU 10, SR_MOS_KIT 10, AL_Sheet 5, HSS_Coil 5, PP_Resin 15, Poly_F_EU 15, EPDM 40, NR_201 40, LGS_4_W 10, TGP_5_Q 10.
- `MFG_LA` in data == `MFG_US`. Network links follow the document; lane statistics come from data pooled by lane type and mode.
- No model id is hard-coded; the model comes from config `decision.model`.
- API key read only from `ANTHROPIC_API_KEY`; never written to any file.
- Tests never call the Anthropic API.
- The source Excel is read-only; the engine uses `data/baseline.json` after `sciti prepare`.
- `runs/`, `data/baseline.json`, `.venv/` are git-ignored.
- Every assumed parameter carries `assumption: true` (catalog) or lives under `assumptions:` (config).
- No dict/set iteration order may affect results: iterate nodes in `Network.order` (fixed id list) and items in sorted order.
- Default markups (assumptions): CM +20%, MFG +25%, DC +10%, retail +40%.
- Customer satisfaction index weights default: fill rate 0.5, on-time 0.3, quality 0.2.
- CO2 (kg) = quantity × 0.05 × miles × factor; factors kg/ton-mile: Air 2.1, Road 0.163, Rail 0.028, Ship 0.037 (Glossary sheet).
